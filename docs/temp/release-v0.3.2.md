# Elfvision v0.3.2 — GNOME build

Antigravity quota monitoring fix for Gemini and Gemini 4 Argon models.

- Send `antigravity/cli/1.4.4 gnome-ai-quota` as default `User-Agent` to receive Gemini and Gemini 4 Argon quota groups from Cloud Code.
- Monitor `Gemini 4 Argon` as a distinct pool alongside standard `Gemini` and `Claude and GPT`.

Install `elfvision-gnome.shell-extension.zip` with `gnome-extensions install --force`.
Existing connectors, credentials, settings, installed fonts and custom themes are preserved.
Log out and back in to load the new extension code on Wayland.
