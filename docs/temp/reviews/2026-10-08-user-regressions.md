## Glassmorphism shadows are clipped at the sides

**Status: corrected; paired native light/dark lateral pixel comparisons pass.** The same owner image shows card shadows above and below the card but cut at its left and right edges. The CSS worker owns the shared template, the shadow-derived scalar in `lib/core/theme.js` and focused theme tests. Any gutter changes must be coordinated with the monetary-header layout because they reduce the space available inside the fixed popup width.

Acceptance requires visible lateral shadow pixels within the same popup viewport and card bounds after the fix, without removing the intended shadow or widening the capture to claim success. Cards/buttons must remain opaque, summary/section headings transparent and decorative allocation, cache invalidation and focus behavior correct. Earlier passing renderer checks remain evidence of the previous source; affected gates require fresh execution after these new changes.

Cause: card containers had no horizontal gutter inside the ScrollView clip, so outer shadows extended beyond its paintable sides. The fix derives per-side padding from the validated shadow's blur, spread and signed offsets, preserving the original shadow and clipping policy. None/inset shadows need no outside gutter. Each side is capped at 64px so extreme custom themes cannot consume the whole popup; such extreme shadows may still be clipped by this documented bound. Dark Glassmorphism reserves `24px 32px 40px 32px`; Aurora's dark lateral gutter is 40px.

The CSS worker reproduced RED **22 passed, 1 failed**, then GREEN **23 passed, 0 failed**, covering all 22 themes in both schemes and signed offsets, spread, fractional values, inset/none, extreme values and injection rejection. Independent review found a P2 regression: the validator accepted uppercase `INSET`/`PX`, but the initial helper parsed them case-sensitively. The worker reproduced that failure, corrected prefix/length parsing and added uppercase regressions; final source preserves original shadow strings. Independent review of that correction found no remaining blocker. These pure checks do not substitute for final native shadow pixels.
