## Corrected findings independently reviewed

- **User override of the System slug:** `themePresentation` requires both loader-owned `builtin === true` and `origin === 'builtin'` before the official System label or trusted catalog description applies. The picker and General selected-theme label share that helper. A user override remains under Your themes with its own name and description. This matches ADR 0006 and does not change the renderer's independent trust restriction.
- **Setup threshold validation:** the pure proposal checks every enabled warning rule before any write. Rejected edits restore the displayed saved value and preserve explanatory feedback through queued unchanged notifications. Valid edits use a dedicated delayed settings object, apply all four quota critical thresholds together, preserve warning settings, and leave shared preferences settings immediate. External rule changes are observed and handlers are disposed.
- **Native evidence:** root's fresh `.superpowers/sdd/2026-10-08-v01/prefs-final.log` records all six LTR/RTL normal/expanded/Sans 22 traversal configurations and all six matching state matrices passing. It includes reopened setup rejection and threshold-pair feedback. The current actual-widget regression starts with weekly warning 80/critical 95, rejects critical 70 without changing any quota, accepts 90 atomically, and checks external changes and reopening. The historical `prefs-setup-red.log` records the intended invalid-edit preservation assertion failing before the fix. Exit 0 for the final runner is supplied by root; this reviewer did not rerun it.
